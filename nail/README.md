# 💅 Nail & Style - Сайт маникюрного салона

Современный, адаптивный сайт для маникюрного салона "Nail & Style" с использованием Bootstrap 5 и множества JavaScript компонентов.

## 🌟 Особенности

### 🎨 Дизайн и UX
- **Современный градиентный дизайн** с розово-золотой цветовой схемой
- **Полностью адаптивный** дизайн для всех устройств
- **Плавные анимации** и переходы с использованием AOS (Animate On Scroll)
- **Стеклянные эффекты** и размытие фона (backdrop-filter)
- **Интерактивные hover-эффекты** для всех элементов

### 🚀 Функциональность
- **Hero-секция** с анимированными счетчиками статистики
- **Карусель услуг** с детальными описаниями и ценами
- **Интерактивная галерея** с фильтрацией по категориям
- **Карусель отзывов** клиентов с рейтингами
- **Форма записи** с валидацией полей
- **Модальные окна** для услуг и записи
- **Toast-уведомления** об успешной отправке
- **Плавная прокрутка** между секциями
- **Кнопка "Наверх"** с анимацией

### 💻 Технологии
- **Bootstrap 5.3.2** - современный CSS фреймворк
- **Bootstrap Icons** - иконочный шрифт
- **AOS Library** - анимации при прокрутке
- **Google Fonts** (Playfair Display + Inter) - красивая типографика
- **Vanilla JavaScript** - интерактивность без зависимостей
- **CSS Custom Properties** - кастомизируемые переменные
- **CSS Grid & Flexbox** - современная компоновка

## 🎨 Кастомизация

### Цветовая схема
Измените CSS переменные в файле `styles.css`:

```css
:root {
    --primary: #e91e63;      /* Основной цвет */
    --primary-dark: #c2185b; /* Темный вариант */
    --secondary: #f8bbd9;    /* Вторичный цвет */
    --accent: #ffc107;       /* Акцентный цвет */
}
```

### Шрифты
Поменяйте импорт Google Fonts в `index.html`:

```html
<link href="https://fonts.googleapis.com/css2?family=YOUR_FONT" rel="stylesheet">
```

### Контент
Отредактируйте текст, изображения и контактную информацию прямо в HTML файле.
