# 🚀 PHP Бэкенд для Nail & Style

## ✅ Что готово

Полноценный PHP бэкенд для сайта маникюрного салона:

### 🗃️ База данных
- **7 таблиц**: пользователи, услуги, мастера, записи, рабочее время, настройки, отзывы
- **Автоматическая установка** через `install.php`
- **Тестовые данные** включены

### 🔐 Аутентификация
- **JWT токены** для безопасности
- **Роли пользователей**: клиент/админ
- **Регистрация и авторизация**
- **Управление профилем**

### 📝 API Эндпоинты
- **`/api/auth.php`** - аутентификация
- **`/api/bookings.php`** - записи клиентов  
- **`/api/admin.php`** - административная панель

### ⚙️ Функции
- ✅ Система записи на услуги
- ✅ Управление расписанием мастеров
- ✅ Статистика и аналитика
- ✅ Управление услугами и мастерами
- ✅ CORS для фронтенда

## 🚀 Быстрый старт

1. **Настрой БД** в `config.php`
2. **Запусти** `install.php` в браузере
3. **Готово!** Админ: `admin@nailstyle-sev.ru` / `admin123`

Подробные инструкции в `SETUP.md`

## 📱 Интеграция с фронтендом

JavaScript клиент `api-client.js` уже готов и интегрирован с существующим фронтендом.
